# The Agentic Practicum

**A hands-on program, not a course: 8 hours over 2 weeks, and every participant leaves with one working agentic pipeline for a recurring piece of their own work.** If your work follows a pattern, you can pipeline it.

Live page: https://dvlevin.github.io/Agentic-Practicum/

By [Dima Levin](https://dimalevin.com), Chief AI Officer and co-founder of [Cone Red](https://cone.red). This repository holds the static landing page (`index.html`) and the proposal (`agentic-practicum-proposal.html`); the course material itself is not public.
