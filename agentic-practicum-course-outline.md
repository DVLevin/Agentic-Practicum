## Who This Is For

This practicum is for any professional who repeats knowledge-heavy processes and wants to build AI systems that actually work with their data. Here's what that looks like across roles:

| Role | The Pain | Pipeline You'll Build | What Changes |
|------|----------|----------------------|--------------|
| **Solution Architect / Presales Engineer** | Spending days assembling proposals from past work, RFP docs, and client research | Research → Draft → Review pipeline that generates tailored proposals from your knowledge vault | Proposals that took 12+ hours now take under 2 — and they're more consistent |
| **Product / Project Manager** | Drowning in status updates, specs, and stakeholder alignment docs | Intake → Synthesis → Report pipeline that turns meeting notes and tickets into structured updates | Weekly reporting goes from half-day grind to a 15-minute review |
| **Marketing / Content Ops** | Creating briefs, campaigns, and copy from brand guidelines, audience data, and past performance | Brief → Generate → Brand-Check pipeline that drafts on-brand content at scale | Content production 3-5x faster with built-in brand consistency checks |
| **HR / L&D Professional** | Writing job descriptions, training materials, and onboarding docs from scattered sources | Template → Contextualize → QA pipeline that generates role-specific materials | New hire onboarding docs in minutes instead of days |
| **Consultant / Analyst** | Researching industries, competitors, and market trends manually for every engagement | Gather → Analyze → Synthesize pipeline that produces structured research briefs | Research phase drops from days to hours with deeper coverage |
| **Compliance / Legal Ops** | Reviewing documents against regulatory frameworks and internal policies | Extract → Cross-Reference → Flag pipeline that checks documents against your policy vault | Compliance reviews that took a team now run as a first-pass pipeline |
| **Technical Writer / Documentation Lead** | Keeping docs in sync with product changes across multiple systems | Diff → Update → Validate pipeline that detects changes and drafts doc updates | Documentation stays current without constant manual triage |

**Common thread:** If you spend hours on a process that follows a pattern — research, draft, review, refine — you can build a pipeline for it here.

## Module Overview

### Module 1: Knowledge Management Foundation
**Duration:** 1.5h | **Practicum Weight:** 70%

**Why This First:** AI tools are useless without structured knowledge. Most people skip this step and wonder why their agents hallucinate.

| Lesson | Title | Time | Outcome |
|--------|-------|------|---------|
| 1.1 | The Brain Architecture | 20min | Understand why knowledge structure precedes tooling |
| 1.2 | Building Your Unified Vault | 40min | Obsidian vault with folder taxonomy + metadata |
| 1.3 | Context-Ready Documentation | 30min | Convert existing docs to AI-parseable format |

**Module Deliverable:** Structured knowledge vault with past work, guidelines, processes—ready for RAG/context injection

**Patterns Applied:** Context Stuffing (P12), YAML-Based User Memory (P14)
